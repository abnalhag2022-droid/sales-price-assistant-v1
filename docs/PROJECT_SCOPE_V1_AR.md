# النطاق المعتمد للنسخة الهاتفية V1

## نواة المبيعات
- شاشة مبيعات سريعة.
- بحث بكلمة واحدة أو جزء من اسم الصنف أو رقم الصنف.
- اختيار العميل.
- استدعاء القائمة السعرية الافتراضية للعميل.
- تغيير القائمة أثناء المعاملة.
- عرض السعر المرجعي من القائمة.
- إدخال سعر البيع الفعلي يدويًا قبل إضافة السطر.
- تعديل الكمية والسعر بعد الإضافة.
- حساب إجمالي الفاتورة.
- إتمام البيع.

## المعاملات المتعددة
- إنشاء معاملة جديدة دون فقد المعاملة الحالية.
- تعليق معاملة.
- استئناف معاملة معلقة.
- الاحتفاظ بعدة معاملات محليًا.

## الاستعلام
- شاشة استعلام أسعار مستقلة.
- عرض السعر لكل قائمة سعرية.
- دعم السعر الثابت للصنف داخل القائمة السعرية إذا أرسله Backend كـ `item_prices`.
- سجل الأسعار والمعاملات.

## التشغيل الميداني
- Local persistence.
- Offline-first.
- Sync Queue.
- Idempotency-Key للإضافات.
- عدم تكرار العملية عند إعادة الإرسال.
- مزامنة عند عودة الاتصال.

## الإدارة
- الأصناف.
- العملاء.
- القوائم السعرية.
- المستخدمون والأدوار الأساسية.
- نسخ احتياطي واستيراد JSON.

## الأدوار الأساسية
- `sales`: المبيعات.
- `store`: المخزن.
- `admin`: الإدارة.

## ما هو مؤجل عمدًا
- التعلم الآلي لاستنتاج السعر.
- OCR/قراءة الفواتير اليدوية.
- الربط النهائي مع ERPNext.
- نسخة الكمبيوتر.
- تقارير متقدمة ومحاسبة كاملة.

هذه ليست إلغاءات؛ هي مراحل لاحقة بعد تثبيت V1 على الهاتف والعمل الحقيقي.
