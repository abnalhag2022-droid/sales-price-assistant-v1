# Requirement Traceability Matrix

مصدر الحقيقة: ملف التسليم العربي المرفوع في المحادثة، خصوصًا أقسام نطاق V1 وقائمة فحص الاعتماد.

| المتطلب | الموضع في الوثيقة | التنفيذ الحالي | الفجوة | الإجراء |
|---|---|---|---|---|
| واجهة عربية RTL | المبادئ وتجربة المستخدم | موجود في `main.dart` وواجهات التطبيق | بعض نصوص البيانات التجريبية تحتاج تنظيف ترميز | تحسين نصوص Demo لاحقًا |
| البحث الجزئي عن الأصناف | نطاق V1 / المبيعات | `AppController.searchItems` | يعمل محليًا، لا يوجد بحث Backend عند Demo | كاف للنسخة الأولية |
| اختيار العميل | المبيعات والعملاء | `SalesScreen` و`customerId` | موجود | كاف للنسخة الأولية |
| قائمة العميل الافتراضية | العملاء وقوائم الأسعار | `selectCustomer` يغير `priceListId` | موجود | كاف للنسخة الأولية |
| تغيير القائمة أثناء المعاملة | المبيعات | `selectList` وتخزين القائمة داخل السطر الجديد | لا توجد شاشة توضيح أثر التغيير | تحسين UX لاحقًا |
| السعر المرجعي والسعر الفعلي | المبيعات | `TicketLine.referencePrice` و`price` | موجود في النموذج، عرض الواجهة محدود | تحسين العرض لاحقًا |
| تعديل السعر والكمية | المبيعات | `editLine` وواجهة تعديل السطر | موجود | كاف للنسخة الأولية |
| تعدد المعاملات | تعدد المعاملات | `tickets` و`activeTicketId` | موجود | كاف للنسخة الأولية |
| تعليق واستئناف | تعدد المعاملات | `pauseActive` و`resume` و`PausedScreen` | موجود | كاف للنسخة الأولية |
| استعلام أسعار مستقل | الاستعلام | `InquiryScreen` | موجود | كاف للنسخة الأولية |
| السجل | السجل | `HistoryScreen` و`history` | محلي فقط | مناسب للنسخة الأولية |
| الإدارة | الإدارة | `AdminScreen` | CRUD محلي وتمهيدي للQueue | مناسب للنسخة الأولية |
| RBAC | الصلاحيات | `UserAccount.can` وإظهار الإدارة للAdmin | Backend غير موجود للتحقق الحقيقي | مؤجل للنسخة الإنتاجية |
| Offline-first | Offline والمزامنة | تخزين ملفي محلي + Queue | لا يوجد Backend لاختبار المزامنة | كاف للنسخة الأولية |
| Sync Queue | Offline والمزامنة | `SyncService` مع status/retry/backoff | يحتاج Backend للتأكيد | مؤجل اختبار إنتاجي |
| Idempotency | API Contract | `X-Idempotency-Key` في `ApiService` | يحتاج Backend | موثق ومهيأ |
| Authentication إنتاجي | Authentication | `ApiService` يدعم access/refresh/401 | التخزين الآمن الحقيقي غير مضاف لتقليل الاعتمادات | تحسين إنتاجي لاحق |
| Backup/Import | النسخ الاحتياطي | `exportBackup` و`importBackup` | موجود | كاف للنسخة الأولية |
| GitHub Actions APK | البناء | `.github/workflows/android-build.yml` | موجود | استخدم `demo_mode=true` |
