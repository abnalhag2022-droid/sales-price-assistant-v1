# بناء النسخة الأولية APK

هذه هي الطريقة الأسرع والأضمن للحصول على نسخة قابلة للتثبيت بدون تجهيز Flutter أو Android SDK على جهازك.

## من GitHub Actions

1. افتح المستودع:
   `abnalhag2022-droid/sales-price-assistant`
2. افتح تبويب `Actions`.
3. اختر `Android Build`.
4. اضغط `Run workflow`.
5. اترك `demo_mode` على `true`.
6. اترك `api_base_url` فارغًا.
7. انتظر انتهاء التشغيل.
8. نزّل Artifact باسم `sales-price-assistant-android`.

## بيانات الدخول التجريبية

- `sales`
- `admin`

في وضع Demo لا تحتاج كلمة مرور.

## حدود النسخة الأولية

- تعمل محليًا على الهاتف للتجربة.
- لا تحتاج Backend.
- تحفظ البيانات محليًا.
- Queue موجودة تمهيديًا، لكن المزامنة الحقيقية تحتاج Backend.
- المصادقة الإنتاجية وRefresh Token تعتمد على Backend مستقبلي.

## معيار نجاح هذه المرحلة

- APK يبنى من GitHub Actions.
- التطبيق يفتح على الهاتف.
- يستطيع المستخدم تنفيذ بيع تجريبي.
- يستطيع تعليق معاملة واستئنافها.
- يستطيع تعديل السعر والكمية.
- يستطيع تصدير نسخة JSON.
